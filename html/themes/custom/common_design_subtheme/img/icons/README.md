# Icon Sprite

This directory contains the source SVG files for the GHI icon sprite.

## Files

- Source icons are individual `.svg` files in this directory, for example `download.svg` or `material-symbol-download.svg`.
- `ghi-icons-sprite.svg` is generated from the source icons and included by the theme.
- `sprite.symbol.html` is a generated preview file from `svg-sprite`.

Do not edit `ghi-icons-sprite.svg` or `sprite.symbol.html` by hand. Update the source SVG, then regenerate the sprite.

## Adding A New Icon

1. Add a single source SVG file to this directory.
   Use kebab-case file names. For Material Symbols, use the `material-symbol-{name}.svg` pattern, for example `material-symbol-open-in-new.svg`.
2. Regenerate the sprite from the theme directory:

   ```sh
   npm run svg:sprite
   ```

3. Use the icon through the wrapper render array when markup is generated by PHP or Twig.
   The icon value can use underscores or dashes; both `open_in_new` and `open-in-new` resolve to `#material-symbol-open-in-new`.

   ```php
   [
     '#theme' => 'hpc_icon',
     '#icon' => 'open_in_new',
     '#tag' => 'i',
   ]
   ```

   ```twig
   {{ {'#theme': 'hpc_icon', '#icon': 'open_in_new', '#tag': 'i'} }}
   ```

4. Use an icon placeholder when markup is generated by JavaScript.
   The theme hydrates `[data-hpc-icon]` placeholders into SVG sprite references via `common_design_subtheme/icons`.

   ```js
   const icon = document.createElement('span');
   icon.className = 'material-icon';
   icon.dataset.hpcIcon = 'open-in-new';
   icon.setAttribute('aria-hidden', 'true');
   ```

   If the placeholder is inserted through normal Drupal behavior attachment, no extra step is needed. Module JavaScript that inserts icons dynamically should attach behaviors on the inserted container:

   ```js
   Drupal.attachBehaviors(container);
   ```

5. Attach `common_design_subtheme/icons` for JavaScript that creates icon placeholders dynamically.
   Theme-owned JavaScript may call `Drupal.hpcIcons.attach(context)` directly when it owns a targeted icon hydration flow.

6. Commit the new source SVG and the regenerated `ghi-icons-sprite.svg`.
   Commit `sprite.symbol.html` if the generated preview changes are intentionally tracked with sprite updates.

## CSS References

For CSS `background-image`, `mask-image`, or similar direct file references, point at the source SVG file rather than the generated sprite.
